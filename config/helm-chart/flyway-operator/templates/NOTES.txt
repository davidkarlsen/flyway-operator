{{- if .Values.metrics.enabled }}
Metrics are served over HTTPS on port {{ .Values.metrics.port }} by the Service
{{ include "common.names.fullname" . }}-metrics in namespace {{ .Release.Namespace }}.
Requests need a bearer token for a ServiceAccount allowed to GET /metrics. Grant it to your
Prometheus ServiceAccount with:

  kubectl create clusterrolebinding {{ include "common.names.fullname" . }}-metrics-reader \
    --clusterrole={{ include "common.names.fullname" . }}-metrics-reader \
    --serviceaccount=<prometheus-namespace>:<prometheus-serviceaccount>
{{- if not .Values.metrics.serviceMonitor.enabled }}

To have the Prometheus Operator scrape it, set metrics.serviceMonitor.enabled=true.
{{- else if not (.Capabilities.APIVersions.Has "monitoring.coreos.com/v1/ServiceMonitor") }}

WARNING: metrics.serviceMonitor.enabled=true but the monitoring.coreos.com/v1 ServiceMonitor API
is not available, so no ServiceMonitor was created. Install the Prometheus Operator CRDs and
upgrade, or disable it.
{{- end }}
{{- end }}
{{- if .Values.grafana.dashboards.enabled }}

The Grafana dashboards are in the ConfigMap {{ include "flyway-operator.fullname" . }}-dashboards in namespace {{ .Release.Namespace }}.
{{- if not .Values.grafana.dashboards.grafanaDashboard.enabled }}
The Grafana sidecar loads it by the label grafana_dashboard.
{{- else if not (.Capabilities.APIVersions.Has "grafana.integreatly.org/v1beta1") }}

WARNING: grafana.dashboards.grafanaDashboard.enabled=true but the grafana.integreatly.org/v1beta1 API
is not available, so no GrafanaDashboard was created. The ConfigMap was created: the Grafana sidecar
loads it by the label grafana_dashboard, or import the JSON from it manually (see docs/dashboards.md).
Install grafana-operator and upgrade to have GrafanaDashboards created.
{{- end }}
{{- end }}
