## For AI Agents

### Working In This Directory
- Use kubebuilder validation markers on every spec field: `+kubebuilder:validation:Required|Optional|Pattern|Enum`, `+kubebuilder:default`. The `JdbcUrl` field already pins `^jdbc:.*`; keep that pattern. Cross-field and key rules are CEL `XValidation` markers (`metadata.name` at most 63 characters, `activeDeadline` range, reserved/invalid `jobMetadata`/`podMetadata` keys, `path` without `..`); keep their messages in sync with the behaviour.
- After editing types, run `make manifests generate` to refresh `config/crd/bases/...` and `zz_generated.deepcopy.go`. Update the examples in `docs/usage.md` if the public shape changed (`config/samples/` is only the minimal OLM `alm-examples` source; keep it valid).
- All operator-specific annotations must be built from the `Prefix` constant. Adding a new annotation or label? Add a const next to `Generation` / `Attempt` / `MigrationLabel`.
- Scheme registration is done in `addKnownTypes` — do **not** reintroduce an `init()` that calls `SchemeBuilder.Register(...)`, and do **not** switch back to the deprecated `sigs.k8s.io/controller-runtime/pkg/scheme.Builder` (`SA1019`). The exported GroupVersion is `flywayv1alpha1.GroupVersion`; there is no `SchemeBuilder.GroupVersion` field on `runtime.SchemeBuilder`.

### Testing Requirements
- `migration_types_test.go` covers the helpers: `go test -count=1 ./api/...`. Behaviour and CEL validation are exercised by the `internal/controller/` tests (envtest) via `make test`.

### Common Patterns
- Status is `[]metav1.Condition` with `patchMergeKey:"type"` and `listType=map` (`Applied`, `Progressing`, `Failed`), plus `observedGeneration`, `attempts`, `lastAppliedImageRef` and `lastAppliedGeneration`.
- Helpers on `*Migration` (e.g. `IsPaused`, `GetConditions`) satisfy interfaces from `redhat-cop/operator-utils` so the reconciler can use its generic helpers.
- `MigrationSource.GetPlaceholdersAsEnvVars()` translates user placeholders into `FLYWAY_PLACEHOLDERS_<KEY>` env vars consumed by the Job spec builder.
